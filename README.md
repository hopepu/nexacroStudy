# Nexacro 학습

2024년 12월, 엔터프라이즈 UI 도구인 **Nexacro**로 화면을 구성해 본 샘플 프로젝트입니다.

- `Base/` 기본 화면, `FrameBase/` 프레임 레이아웃, `Popup/` 팝업 화면
- 애플리케이션 설정: `Application_Desktop.xadl`, `environment.xml`, `typedefinition.xml`

## 기술
Nexacro N

---

현재 SAP BTP 실무 포트폴리오는 [sap-btp-portfolio](https://github.com/hopepu/sap-btp-portfolio)에 정리하고 있습니다.
